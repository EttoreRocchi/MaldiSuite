Why MaldiSuite

A whole AMR study, written as one scikit-learn pipeline.

Shared data model

MaldiSpectrum and MaldiSet carry species, batch, MIC and acquisition metadata through every step, with no manual bookkeeping of sample identities.

Leak-safe by construction

Every transformer is fitted on the training folds and applied unchanged to held-out data, and grouped cross-validation keeps the spectra of one isolate in the same fold.

scikit-learn native

Correctors and classifiers are estimators, so Pipeline, cross_val_score and GridSearchCV work without glue code.

Reproducible

Fixed seeds, versions pinned by the meta-package and a Bruker-native data path make reruns deterministic from raw spectra.

Workflow

Raw spectra in, resistance predictions out.

Each package covers one stage of the workflow and hands the next one the same MaldiSet, so the three stages run as steps of a single Pipeline.

  1. Raw spectra

    Bruker fid/1r, txt, mzML/mzXML

    + metadata: species, drug, MIC, site, date

  3. Preprocessing

    MaldiAMRKit

    • I/O and dataset layouts
    • Preprocessing pipeline
    • Warping and peak detection
    • AMR metrics, grouped CV
  4. MaldiSet 6000 bins

  5. Harmonisation

    MaldiBatchKit

    • 11 correctors
    • MALDI-specific corrections
    • kBET, LISI, silhouette
    • Fit on train, apply to held-out
  6. harmonised MaldiSet

  7. Classification

    MaldiDeepKit

    • MLP, 1-D CNN, ResNet, 1-D ViT
    • Any bin layout
    • Uncertainty estimates
    • Leak-safe warping and scaling

  9. Predictions

    R / S per isolate

    scored with VME, ME and AUROC

Batch labels are needed only for the harmonisation step: single-site studies use MaldiAMRKit and MaldiDeepKit directly.

Packages

Three packages, one install.

Each package has its own repository, documentation and release cycle. Install them one by one, or all together with the maldisuite meta-package.

v0.22.1

MaldiAMRKit

Data model, preprocessing and AMR-aware evaluation

  • Bruker fid/1r, txt and mzML/mzXML I/O, with DRIAMS and MARISMa layouts
  • Composable PreprocessingPipeline, serialisable to JSON/YAML
  • Seven warping methods, on binned or full-resolution spectra
  • VME, ME and categorical agreement, with patient-grouped splitters
  • MIC encoding with bundled EUCAST breakpoint tables
  • Differential analysis and drift monitoring
pip install maldiamrkit
GitHub PyPI Docs
v0.2.0

MaldiBatchKit

Batch-effect correction for multi-site spectra

  • ComBat (Johnson, Fortin, CovBat), Limma and Harmony
  • MALDI-specific BatchAwareWarping, QualityWeightedComBat and SpeciesAwareComBat
  • Fitted on training data, applied unchanged to held-out folds
  • AutoCorrector to pick the corrector inside GridSearchCV
  • kBET, LISI and silhouette diagnostics, and BatchCorrectionBenchmark
  • MaldiSetAdapter and a command-line interface
pip install maldibatchkit
GitHub PyPI Docs
v0.3.0

MaldiDeepKit

Deep-learning classifiers for binned spectra

  • MaldiMLPClassifier, MaldiCNNClassifier, MaldiResNetClassifier and MaldiTransformerClassifier
  • Defaults tuned for 6000-bin spectra, from_spectrum() for other layouts
  • Dual-branch (spectrum + side features) and self-training classifiers
  • MC Dropout, Laplace and split conformal uncertainty
  • Warmup + cosine schedules, focal loss, SWA, SAM and temperature scaling
  • Leak-safe warping, fitted on the training split only
pip install maldideepkit
GitHub PyPI Docs

Quick start

From a folder of spectra to a cross-validated score.

  1. 1Install

    pip install maldisuite

    Python 3.10 or newer. The deep models run on CPU; a CUDA GPU makes training much faster.

  2. 2Load your cohort

    Point MaldiSet at a folder of spectra and a metadata CSV with an ID column for each spectrum, the resistance label, species, batch and patient. Labels are encoded as R = 1, S = 0.

  3. 3Build and evaluate the pipeline

    Warping, ComBat and the classifier are refitted inside every training fold, and CaseGroupedKFold keeps all spectra of a patient in the same fold.
